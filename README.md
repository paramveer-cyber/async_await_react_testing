# Pokemon Moves Explorer
A small React demo that fetches and displays which moves a Pokémon can perform using async/await — built for testing and learning.

Features:
- Demonstrates async/await with React data fetching.
- Shows a move list for a selected Pokémon.
- Includes simple tests illustrating async behavior in components.

Quick start:
1. Install: `npm install`
2. Run: `npm start`
3. Tests: `npm test`

Live demo: https://async-await-react-testing.vercel.app
